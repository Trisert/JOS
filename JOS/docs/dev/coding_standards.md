# Coding Standards

- **Language:** C (C11, `gnu11` in the Makefile). MISRA guidelines for safety.
- **No dynamic allocation after init:** no `malloc`/`free` inside tasks.
- **Interrupt-driven I/O:** all SPI/I2C must be non-blocking (DMA + ISR). No
  `HAL_SPI_Transmit` polling in tasks.
- **Watchdog:** every task registers on init.
- **State machine** lives only in `App/obsw/state_machine.c`.
- **User-code sections:** when generated by CubeIDE, keep changes between
  `/* USER CODE BEGIN */` / `/* USER CODE END */`. (CubeIDE is optional — see
  `building.md`.)
- **Prototypes:** declare all cross-module functions in the relevant `App/*/*.h`.
  Implicit declarations are a hard error on every toolchain (`-Werror=implicit-function-declaration`; GCC >= 14, including CI's 14.3, rejects them natively).
